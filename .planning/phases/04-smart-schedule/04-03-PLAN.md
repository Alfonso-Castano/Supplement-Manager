## Tasks

### Task 1 — Rewrite `ScheduleView.swift`

**File:** `StackWise/Features/Schedule/ScheduleView.swift` (REWRITE)

Structure:
- Inject `@Environment(ScheduleStore.self) private var scheduleStore`
- Inject `@Environment(\.managedObjectContext) private var context` to fetch `UserProfile` for time window display
- Call `scheduleStore.currentSchedule()` in a computed property to get `ScheduleResult`
- `List` with three `Section` headers (Morning / Afternoon / Evening) — suppress empty sections entirely (same pattern as `AnalysisView`)
- If all blocks are empty → `ContentUnavailableView("No schedule yet", systemImage: "calendar.badge.exclamationmark", description: Text("Add items to your stack to generate a schedule."))`

**Section header format:**  
`"Morning · 7:00–12:00 PM"` — build `blockTimeWindow(block:profile:)` helper that formats the range using `UserProfile` times:
- Morning: `wakeTime` → `lunchTime`
- Afternoon: `lunchTime` → `dinnerTime`
- Evening: `dinnerTime` → `sleepTime`

Use `DateFormatter` with `.short` time style.

**Item row — private `ScheduleItemRow` struct:**
```
[label]                     [badge icons]
[dosage] · [Rx if prescription]
```
Badges (trailing):
- Red octagon (`exclamationmark.octagon.fill`, `.red`) — if `hasSynergy == false` and item appears in a timing-conflict pair (check `AnalysisStore.currentResults()?.critical` pairs for the slug) — simplification: show only if the item has any critical interaction with another stack item.
- Green checkmark circle (`checkmark.circle.fill`, `.green`) — if `hasSynergy == true`.
- Blue `Rx` badge — if `isPrescription == true`.

Inject `@Environment(AnalysisStore.self)` into `ScheduleItemRow` to check severity badges — reuse `worstSeverity(forSlug:)` from `AnalysisResults`.

**Note on `displayName`:** The slug → display name helper in `AnalysisView` can be duplicated locally for now (same `slug.replacingOccurrences(of: "_", with: " ").capitalized` pattern). If it's needed in 3+ places by Phase 5, extract to a shared `LabelService` then.
