- **D-01:** Playwright MCP is the sole MCP runtime tool for Phases 12–15. Already configured in `.mcp.json`. Verified 2026-05-19 against `localhost:4322` — full-page screenshots at 1440px and 375px both succeeded.

- **D-03:** No axe accessibility MCP. No formal a11y audit scope in Phases 12–15.

### Claude Skills
- **D-04:** Taste skill suite installed from https://github.com/Leonxlnx/taste-skill — 12 skills in `.agents/skills/`. Most relevant for Phase 12: `design-taste-frontend`, `high-end-visual-design`, `redesign-existing-projects`, `minimalist-ui`.
- **D-05:** UI/UX Pro Max rejected — heavyweight greenfield generator; design system is already locked from Phase 10 (colors, fonts, tokens in `global.css`).
- **D-06:** Frontend Design skill from aitmpl.com not separately installed — overlaps with Taste; Taste's `design-taste-frontend` covers the same anti-"AI slop" ground.

### TOOLS.md
- **D-07:** TOOLS.md written as quick reference (not a full decision log) to `planning/phases/12-landing-polish/TOOLS.md`. Includes: selected tools with invocation guide, rejected tools with reason, quick-reference shell commands.

- **D-08:** SkillUI approved as the standard tool for taking visual inspiration from any real website. Install: `npm install -g skillui` + `npm install -g playwright && npx playwright install chromium`. Output goes to `landing/.agents/skills/frontend-references/{site-name}/{site-name}-design/`. Frontend skill references are always stored in this subfolder to keep them separate from general Taste skills. Use it whenever the user says "I want this to feel more like X" or asks for inspiration from an external site. First references extracted: `suppco` (https://supp.co/) and `duolingo` (https://www.duolingo.com/) in Phase 12.

### Claude's Discretion
